## Objetivo
Analisar performance de vendas por continente, produto e ano.

## Ferramentas
- Power BI
- DAX
- Power Query

## KPIs
- Receita total
- Ticket médio
- Crescimento mensal
- Meta vs realizado

## Insights
- Continente da América do Norte representa 60,12% das vendas.
- O produto mais vendido "Mouse sem fio MO251 2.4 Ghz", representa 9,46% das vendas totais.
- Marca "Valio", detém a maior porcentagem de produtos devolvidos, representando 8,33% do total.
